# Identidade visual MRBE

O brasao foi criado especificamente para o projeto MRBE Linux TV. O arquivo original, a versao com transparencia e a versao otimizada estao nesta pasta.

A licenca MIT do codigo-fonte do launcher nao deve ser interpretada automaticamente como licenca para todos os elementos visuais. Antes de publicar o repositorio, o mantenedor deve definir e registrar a licenca de distribuicao dos assets de marca. O desenho nao incorpora logos oficiais do Google TV, Netflix ou Disney+.
